Como organizar o PowerPoint e as planilhas

Não existe nome obrigatório de arquivo. Existem poucas regras de formato — elas estão todas aqui.

01

O que a ferramenta consegue atualizar

Objeto real, não imagem
Ela enxerga
  • Gráfico de verdade — o que abre em Editar dados ao clicar com o botão direito.
  • Tabela de verdade do PowerPoint — aquela em que dá para clicar dentro de uma célula e digitar.
  • Caixa de texto — usada para números soltos no slide.
  • Objetos dentro de grupos continuam sendo encontrados.
Ela não enxerga
  • Print, foto ou gráfico colado como imagem — vira figura, não tem dados dentro.
  • Tabela colada do Excel como imagem ou como objeto vinculado.
  • SmartArt e desenhos.
  • Qualquer coisa fora do slide (mestre, layout, anotações).

Teste de 5 segundos no seu deck: clique no objeto com o botão direito. Se aparecer Editar dados (gráfico) ou der para digitar dentro da célula (tabela), a ferramenta atualiza. Se só aparecer opções de imagem, aquele objeto precisa ser refeito como gráfico/tabela nativo.

02

Organizar o PowerPoint

Seu arquivo nunca é alterado
  • Envie o deck já no layout final. A ferramenta troca números, não move nem redesenha nada — cores, fontes, eixos e rótulos ficam como estão no seu arquivo.
  • Deixe cada gráfico com a estrutura certa. O Editar dados define o contrato: quantas séries, quais categorias. Se a planilha vier com linhas e colunas invertidas, a ferramenta transpõe sozinha; mas se o gráfico tem 3 séries e a planilha só traz 2, sobra série vazia.
  • Não precisa renomear formas. O nome numérico da forma (ex.: 7792738590) é usado como atalho quando existe, mas o match funciona por conteúdo.
  • Slides repetidos são tratados separadamente. Cada gráfico é um objeto próprio, mesmo que o slide seja duplicado.
  • Vai atualizar só parte do deck? Use o campo Slides para atualizar (ex.: 3, 5, 8-10). Deck grande fica mais rápido e o resto não é tocado.
Deck que se repete todo mês: prepare um modelo

Em Preparar modelo a ferramenta lê o deck uma vez, dá um ID estável para cada gráfico/tabela e devolve duas coisas: uma cópia identificada do PPT (com os IDs à vista) e uma planilha de mapeamento onde você diz, por objeto, qual arquivo e qual aba alimenta ele.

Depois disso, a rodada mensal vira só "enviar as planilhas do mês": sem IA, sem adivinhação, e objetos marcados como inativos nunca são alterados.

03

Organizar as planilhas

Uma planilha por objeto
  • Um bloco de dados por gráfico/tabela. Pode ser um arquivo por objeto ou uma aba por objeto — o que for mais natural para você.
  • Primeira linha = títulos das colunas. Primeira coluna = rótulos das linhas. Nada de linha em branco, logo ou título mesclado antes do cabeçalho.
  • Sem colunas auxiliares coladas na tabela. Deixe pelo menos uma coluna/linha vazia separando cálculos de apoio, ou marque o intervalo como Tabela do Excel.
  • Linhas e colunas podem estar invertidas. A ferramenta compara com o Editar dados do gráfico e transpõe quando preciso.
  • Várias tabelas na mesma aba? Funciona, mas dá trabalho a mais: no preview você pode apontar o intervalo exato (ex.: Base!A1:D10).

04

Nome dos arquivos

Livre — mas dá para ajudar

Nenhum nome é obrigatório: a ferramenta compara conteúdo (categorias, séries, título perto do gráfico) para descobrir qual planilha é de qual objeto. Estes dois hábitos deixam o acerto imediato:

  • slide3 no nome do arquivo (ex.: satisfacao_slide3.xlsx) — restringe a busca àquele slide.
  • Célula de contexto com obj + número da forma (ex.: obj3958478347) — match exato, sem disputa. As planilhas exportadas pelo Preparador de Modelo já saem assim.

Renomeou tudo no mês seguinte? Sem problema: depois do primeiro download bem-sucedido o squad ganha uma memória de mapeamento que reconhece as planilhas pelo conteúdo, mesmo com nome novo ou deck refeito.

05

Números, percentuais e fórmulas

Valor entra igual saiu
  • Número tem que ser número, não texto. 62,4 sim; "62,4%" não.
  • Não multiplique nem divida por 100. Escreva o valor como ele deve aparecer; o % é exibido só se o próprio gráfico já usa formato percentual.
  • O valor gravado é idêntico ao da planilha, com todas as casas decimais. A exibição no preview usa 1 casa.
  • Fórmulas simples são calculadas: SOMA, MÉDIA, MÍNIMO, MÁXIMO, CONT.NÚM, CONT.VALORES, SE, SOMASE, CONT.SE, SOMARPRODUTO.
  • Evite fórmula que puxa outro arquivo (link externo), tabela dinâmica como fonte e funções fora dessa lista — nesses casos a rodada avisa em vez de gravar número errado. Cole como valor.

06

Checklist antes de enviar

1 minuto
  • Todo gráfico/tabela que precisa mudar é objeto nativo (abre Editar dados), não imagem.
  • Existe um bloco de dados para cada objeto que vai mudar.
  • Cabeçalho na primeira linha e rótulos na primeira coluna, sem linha em branco antes.
  • Números como número, sem % digitado e sem multiplicar por 100.
  • Fórmula complexa ou link externo colado como valor.
  • (Opcional) slide<N> no nome do arquivo.
  • Planilhas juntas num .zip ou selecionadas de uma vez no campo de upload.

07

Deu errado? O que costuma ser

Antes de pedir ajuda
O gráfico não apareceu no preview
Provavelmente é imagem, não gráfico. Ou o slide ficou fora do campo Slides para atualizar.
Apareceu, mas sem planilha ligada
Nenhum arquivo bateu por conteúdo. Escolha a planilha na mão no preview — a escolha vira memória do squad para a próxima vez.
Ligou na planilha errada
Duas planilhas parecidas demais. Troque no preview; se o deck é recorrente, use o Preparador de Modelo para fixar a ligação.
Números certos, série vazia no gráfico
O gráfico espera mais séries/categorias do que a planilha traz. Compare com o Editar dados do gráfico original.
Valor virou texto / ficou zerado
Célula formatada como texto, % digitado junto ou fórmula não suportada.
